# Third-Party Notices

## MR.Jobs

Jobops preserves and extends the Git history of [humancto/mr-jobs](https://github.com/humancto/mr-jobs). The inherited and modified MR.Jobs code is licensed under the MIT License included in [`LICENSE`](LICENSE).

Substantial inherited areas include job discovery and scoring utilities, the legacy dashboard and CLI, CSV queue helpers, LLM backend integration, browser-session utilities, and the historical generic application implementation now quarantined under `adapters/legacy/` for regression compatibility.

Jobops adds the Private Home, structured outcomes, Event Ledger, leases, two permits, deterministic Adapter Protocol, supported ATS adapters, Workday state machine, Security.framework credential backend, compact generic adapter, browser broker, Node bridge, and Codex Skills.
