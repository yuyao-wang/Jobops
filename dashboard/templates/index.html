    Track every application

    Saved outcomes are shown in five user-facing stages while formal execution records remain unchanged.

    Starting resumes an already prepared eligible application first. If none can resume, it enables automatic-application intent for every enabled search profile, refreshes the job library and Priority decisions, then processes eligible jobs one at a time. For P2 jobs, Start also approves the exact prepared materials at Gate A. JobOps still pauses for final review and submit confirmation, missing verified answers, CAPTCHA, MFA, or uncertain submission evidence; Start never approves Gate B.
